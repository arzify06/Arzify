# Desire Luxe Interiors - Vehicle Ceiling Interior Website

A fully responsive, premium vehicle interior website built with HTML, CSS, and JavaScript.

## 🚀 Getting Started

1. Open `html/index.html` in your web browser to view the website
2. For admin access, navigate to `html/admin-login.html`

## 📁 Project Structure

```
├── html/           # All HTML pages
├── css/            # Stylesheet files
├── js/             # JavaScript files
└── images/         # Image assets folder
```

## 👤 User Features

- **Home Page**: Browse featured products
- **Products Page**: View all products with category filtering
- **Registration/Login**: Create account and login
- **Profile**: View user profile information
- **Orders**: Track order status
- **Contact**: Send messages to admin
- **Payment**: Complete orders with multiple payment options

## 🔐 Admin Features

**Default Admin Credentials:**
- Username: `admin`
- Password: `admin123`

**Admin Panel Includes:**
- Dashboard with statistics
- User management
- Product management (Add, Edit, Delete)
- Order management (View, Update status)
- Contact messages management
- Profile management

## 💾 Data Storage

All data is stored in browser localStorage:
- Users
- Products
- Orders
- Contact messages
- Admin credentials

**Note:** Data persists in the browser. To reset, clear browser localStorage.
